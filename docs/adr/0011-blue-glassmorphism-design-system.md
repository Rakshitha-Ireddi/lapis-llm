# 0011. Blue (#0000FF) glassmorphism design system

- **Status:** Superseded by [0013](0013-monochrome-liquid-glass.md)
- **Date:** 2026-11-09

## Context

The project needs a recognisable identity across the website and console, in light and
dark themes, without a component library. The name refers to lapis lazuli, a deep blue
stone.

## Decision

- **Brand colour is pure blue `#0000FF`.** It is used for fills (primary buttons, active
  nav, chart series, meters), where white text on it has an 8.6:1 contrast ratio. On the
  dark theme, blue *text* uses a lighter tint (`#9A9AFF`) to stay readable.
- **Glass surfaces**: translucent panels (`rgba(255,255,255,.055)` dark /
  `.55` light), `backdrop-filter: blur(18px) saturate(160%)`, a 1 px light border and a
  subtle specular top edge, floating over a fixed backdrop of slowly drifting blue
  orbs and a faint grid.
- All colours are CSS custom properties on `:root`, redefined for dark mode via
  `prefers-color-scheme` and an explicit `data-theme` override that is remembered.
- Typography: Space Grotesk (display), Inter (body), JetBrains Mono (code/numbers).
  Fonts load non-blocking; system fonts are the fallback.
- Motion respects `prefers-reduced-motion`.
- Status colours (green/amber/rose) are reserved for state, never decoration.

## Consequences

- One stylesheet (`glass.css`) styles both pages; page-specific layout lives in
  `landing.css` and `console.css`.
- `backdrop-filter` costs GPU time on low-end devices; surfaces stay readable without it
  because the fallback background is opaque enough.
- Screenshots in `docs/screenshots` are regenerated by Playwright, so the README always
  matches the real UI.
